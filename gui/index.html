👋 ¿Primera vez? Sigue estos 3 pasos:
  1. Plan: en la pestaña 📝 Plan, pega tu análisis y pulsa "🤖 Generar plan con Claude" (o escribe el plan a mano). Claude (Opus) lo convierte en tareas.
  2. Orquestar: en 🎯 Orquestar, pulsa "🔍 Parsear tareas", elige qué IA ejecuta cada una (claude/codex/kilo/opencode/vibe) y pulsa "🚀 Lanzar".
  3. Observar: en 🖥️ Terminales ves a todas las IAs trabajando en vivo. O pulsa "🖥️ Abrir terminal" para lanzar la IA en una ventana real del sistema.

📐 Formato esperado del plan.md

Para que el orquestador detecte las tareas, usa este formato (o pulsa "Generar plan con Claude" que lo produce automáticamente):

## Fase 1 — Consolidar PS1

### Tareas

- [ ] Auditar motor PS1 actual (agente sugerido: explorer)
- [ ] Documentar contratos del núcleo (agente sugerido: spec_author)
- [ ] Crear pruebas reproducibles (agente sugerido: implementer)

## Fase 2 — PS2, PSP

### Tareas

- [ ] Implementar backend PS2 (agente sugerido: implementer)
- [ ] Implementar backend PSP (agente sugerido: implementer)
- [ ] Revisar compatibilidad (agente sugerido: reviewer)

Reglas: el parser detecta secciones con "fase/task/paso" y extrae sus bullets. Cada tarea debe tener (agente sugerido: ...). Sub-tareas indentadas se ignoran. Notas/Objetivo/Contexto no aportan tareas. Ver plan-template.md para el formato completo.
